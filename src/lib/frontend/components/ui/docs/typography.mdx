# Typography

## Families

| Token | Current stack | Use |
| --- | --- | --- |
| `--font-sans` | JetBrains Mono, Berkeley Mono, IBM Plex Mono, system monospace fallbacks | Default application copy |
| `--font-mono` | JetBrains Mono, Berkeley Mono, IBM Plex Mono, system monospace fallbacks | Code, paths, and data |
| `--font-brand` | Chakra Petch, sans-serif | Branded controls and headings |

`--font-sans` and `--font-mono` intentionally resolve to the same stack today.
Use `font-sans`, `font-mono`, or `font-brand`; do not repeat a font-family list in a
component.

## Size scale

The text utilities use this conduit-owned scale from `style.css`:

| Utility / token | Size | Line height |
| --- | ---: | ---: |
| `text-xs` / `--text-xs` | 10px | 1.4 |
| `text-sm` / `--text-sm` | 11px | 1.4 |
| `text-base` / `--text-base` | 12px | 1.5 |
| `text-lg` / `--text-lg` | 15px | 1.4 |
| `text-xl` / `--text-xl` | 20px | 1.3 |
| `text-2xl` / `--text-2xl` | 24px | 1.2 |

## Weight gap

Font weights are not tokenized in `style.css`. Components currently use Tailwind's
`font-medium`, `font-semibold`, and `font-bold` utilities. Treat that as the current
convention and an open design-system gap; do not invent `--font-weight-*` tokens in a
feature.
