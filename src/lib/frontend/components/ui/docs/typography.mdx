# Typography

## Families

| Token | Current stack | Use |
| --- | --- | --- |
| `--font-sans` | Geist, system-ui, sans-serif | Default application copy, controls, and headings |
| `--font-mono` | Geist Mono, ui-monospace, monospace | Code, paths, and data |

Both families are self-hosted variable fonts. Geist Mono uses `size-adjust: 92%`
on its font faces. Use `font-sans` or `font-mono` rather than repeating a stack.
The terminal keeps IBM Plex Mono.

## Size scale

The text utilities use this conduit-owned scale from `style.css`:

| Utility / token | Size | Line height |
| --- | ---: | ---: |
| `text-xs` / `--text-xs` | 12px | 1.4 |
| `text-sm` / `--text-sm` | 12.5px | 1.4 |
| `text-base` / `--text-base` | 13px | 1.5 |
| `text-lg` / `--text-lg` | 13.5px | 1.4 |
| `text-xl` / `--text-xl` | 15px | 1.3 |
| `text-2xl` / `--text-2xl` | 17px | 1.2 |

## Weight gap

Font weights are not tokenized in `style.css`. Components currently use Tailwind's
`font-medium`, `font-semibold`, and `font-bold` utilities. Treat that as the current
convention and an open design-system gap; do not invent `--font-weight-*` tokens in a
feature.
