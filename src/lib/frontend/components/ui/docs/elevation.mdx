# Elevation

Every elevation token embeds `rgba(var(--shadow-rgb), …)`. `computeVars` supplies
that channel for the active theme, so the shadow remains part of the runtime theme.
A hand-written shadow string is always wrong: use the semantic shadow utility.

In Tailwind classes these are `shadow-menu`, `shadow-menu-lg`, `shadow-panel`,
`shadow-modal`, and `shadow-dropdown`. Choose by surface role, not by which shadow
looks strongest in one theme.
