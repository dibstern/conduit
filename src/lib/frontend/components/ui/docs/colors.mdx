# Colors

Conduit has a **24-theme runtime theming system**. The theme-derived values in
`style.css` are defaults: `computeVars` in `stores/theme-compute.ts` derives the
active theme and `applyTheme` writes those CSS variables onto `:root` at runtime.
Never hardcode a hex value. Consume the semantic token so the UI follows the active
theme.

The brand pair and its glow tokens are deliberately invariant across user-selected
themes. `--color-backdrop` remains theme-aware through the runtime `--overlay-rgb`
channel.
