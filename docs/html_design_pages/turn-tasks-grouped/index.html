Turn tasks: grouped by kind, 5 designs

Subagents and shells in their own groups, finished folded away, list or table with a detail view

Round three. All five use what you picked: tasks grouped by kind (design 10), finished tasks folded away, and the list and table with a detail view (designs 1 and 2). The head chips stay. Finished tasks fold into one ✓ 2 done chip, and tapping it opens the Tasks tab with finished shown.

Same moment in all five: two subagents running, one of them running its own pnpm test:unit, a vitest watcher, and two finished tasks (one subagent, one shell). Open session → is on every subagent, finished ones too.

Five designs

5
1

Grouped list, detail beside

↗

Design 2's list, split into Subagents and Shells sections. Each section ends in one dim line for its finished tasks, closed by default. The tapped chip picks the detail. Subagent rows also carry a small arrow, so you can jump to a session without opening the detail first.

2

Grouped table, detail below

↗

Design 1's table at full width, with a header row per kind showing its totals. The selected row's detail docks under the table across the full width. Finished tasks from both kinds share one line at the bottom of the table. Best on a wide screen when you want to compare tasks.

3

Row opens in place

↗

A grouped table where the selected row opens into its own detail, so list and detail stay in one column. This is the one that still works on a phone. Finished tasks hide behind a small link on each kind's header.

4

Detail fits the kind

↗

The same split, drawn with a shell selected to show that the detail changes by kind. A shell shows its output, pid and who started it. When a subagent started it, that line links to the subagent's session. Finished is drawn open here: one tap from the ✓ 2 done chip, and each finished subagent keeps its Open session.

5

Kind tabs

↗

Instead of sections, a switch at the top picks one kind, and Finished is its own tab, out of sight until you want it. Since a table only shows one kind, it can use columns that fit: model, steps and cost for subagents; pid and output for shells. The detail sits in a narrow pane on the right.

Shared rules

  1. Finished stays folded until you open it, and it stays open for that turn once you do. Tapping the ✓ 2 done chip opens the Tasks tab with finished shown.
  2. Subagents always get Open session →, running or finished. Shells get Output and Stop. A shell started by a subagent links to that subagent's session.
  3. The tapped chip picks the detail. With no chip tapped, the first running subagent is selected.
