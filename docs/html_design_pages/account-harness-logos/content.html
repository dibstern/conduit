Direction: HarnessLogo tile + account badge, everywhere an account appears. It reuses HarnessLogo as-is: a Claude tile is clay with a white mark; Codex, Cursor and OpenCode tiles are neutral chips. The coloured letter badge (the account's identity colour) appears only when that harness has 2+ accounts, which is the component's existing rule, so single Codex and Cursor accounts show a bare tile.

Alignment: in lists, every tile reserves the badge's gap even when unbadged, so names line up across groups. Standalone tiles (harness row, composer chips) don't reserve it.

OpenCode has no plan usage, so it never appears in the usage footer or Settings → Usage. Its accounts show up in Settings → Accounts and the composer picker.
