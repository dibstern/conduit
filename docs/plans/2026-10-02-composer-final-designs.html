Field width · keeping V1's icons from crowding the text

The problem: + │ field │ logo │ meter │ shield │ send leaves the text about 120px, so a sentence wraps into a narrow column, and "Reply to steer…" gets cut off. Three fixes, each shown in the cases that broke. All three follow one rule: text that can't fit on one line always gets the full width. The captions show each composer's measured height, so you can compare the cost.

The Field width choice in the top bar also drives all 25 states below. V3 follows the same rule automatically, which matters when stop and send both show.

My pick
W2. It costs nothing when idle, and your text gets the full width the moment it needs it. The grey placeholder can never be cut off, because "doesn't fit" is measured, not guessed. ChatGPT's iPhone app does the same, so it already feels familiar.
Runner-up
W1 if the one-time jump in W2 bothers you. It's calmer and simpler to build, and it's always 34px taller.
Build note
W2 measures with the real text box, which is cheap, but it needs one check on every keystroke and on resize.

V1 icons and V3 words · switchable in Settings

Both get built, so you can live with each before deciding. The setting sits under Settings › Composer, and the mock on the right really switches this page.

V3 gotcha
The words sit near the home-bar swipe zone. Taps work, but an upward flick from that row goes home. Fine for settings. Send and stop stay out of it.

Shield and effort · micro labels, tap to cycle, hold for the menu

Each mode has its own colour and word. Only Ask is grey, so any colour means "not the default". The approvals menu and desktop chip use the glyph shield instead, since a text label already sits beside it.

Order
Plan → Ask → Edits → Auto → Full access → Never ask. OpenCode cycles only Ask → Edits → Full access.
Risk
One stray tap from Auto lands on Full access. You picked this knowingly. The red shield and its FULL label make it obvious, and one more tap moves on to Never ask.

Picker · P2 drill-down, pick effort directly

Effort shows every level the model has, xhigh included, and you tap the one you want. Context, with only two sizes, toggles in place. Harness and Model drill in because they're real lists. The OpenCode logo is now the real mark from opencode.ai.
