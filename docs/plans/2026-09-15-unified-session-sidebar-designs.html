Unified session sidebar · 25 designs

Drop the project switcher as a container; show every project's sessions in one sidebar with filtering and grouping. Ten designs stay inside web-interface best practice, fifteen don't. Every mockup uses the same eight sample sessions across four projects so they compare fairly.

Every design now carries t3code's settle v2 lifecycle: sessions are cards while active, park as slim rows in a collapsed Settled shelf when done (by hand, or automatically by the server), and can be snoozed. Rules and anatomy are in the first section.

§0 · Settle v2 lifecycle (from t3code)

Three shelves, one overlay. Active rows are full cards; Settled rows are slim, quiet, and collapsed by default; Snoozed is an overlay on Active with a wake time. Pinned is a flag, not a shelf. The server settles work on its own while the app is closed, and the sidebar never second-guesses density: only settling or snoozing collapses a row.

§0.1

Anatomy: Pinned / Active / Snoozed / Settled + chat banner

Card rows hover to reveal ✓ settle in the time slot. Settled rows sit at 70% ink, glyph desaturated, and hover to reveal ↶ un-settle; their time is when they settled, not last activity. A woken snooze shows a Woke pill in its original slot until visited. Opening a settled session shows a banner; sending a message un-settles it.

Keys: ⌘⇧S settle / un-settle · ⌘⇧P pin · drag onto the Settled header · thread menu.

§0.2

Drag onto the Settled header

Mid-drag the row swaps its status and time for the verb the drop will perform (Pin / Unpin / Settle / Un-settle / Wake), the target section takes the accent, other rows slide aside. Dragging out of Settled un-settles; nothing can be dragged into Snoozed because snoozing needs a wake time.

Twins: every drop has a menu item and a shortcut; reduced-motion drops the slide.

§0.3

Snooze menu + woken session

Presets are computed from now (1h, 3h, this evening only while it's meaningfully before 6pm, tomorrow 9:00, next week, custom). You can snooze a running session, never one that's blocked on you. Anything that outranks the snooze raises its hand and wakes it early: an approval, a question, a fresh error, or a turn finishing after the snooze was set.

Sort stays static: a woken session reappears where it was, so the Woke pill carries the signal until you visit.

Manual settle

  • ✓ on card hover, ⌘⇧S, menu, or drag onto the Settled header.
  • Settling clears the pin and the manual Active slot ("done" beats "keep on top").
  • Settling an idle session dismisses unanswered questions without answering them.
  • Un-settle (↶, banner, or just send a message) returns it to the top of Active and blocks auto-settle until new activity resumes the rules.

Auto settle (server, runs while the app is closed)

  • Idle for N days, default 3, range 1–90, or off.
  • Linked PR merged (default on), or an idle session's PR closed. conduit analogue: branch merged into main / worktree removed.
  • An old merge doesn't settle work you resumed after it: the PR's terminal time must be newer than your last message.
  • Settled time is the last activity, so the shelf reads "wrapped up 3d ago".

Per project override, changing a rule never reopens already-settled sessions.

Never auto-settles while

  • Pending approval or question (hiding the request would defeat it).
  • Session starting or running, or background work alive (PTY, dev server).
  • A queued message under 2 min old that no turn has adopted yet.
  • Manually un-settled, or snoozed with time left (unless it raised its hand).

Rendering

  • Only Settled and Snoozed collapse a row to slim. Every Active row is a card; density comes from parking work, not from the sidebar guessing.
  • Settled rows: 70% ink and desaturated glyph until hover; PR number colours on hover only (open emerald, merged violet, closed red, draft grey).
  • Both shelves collapsed by default, remembered per device. Settled tail shows 10, then +25 per Show more.
  • Active order is static: activity never reorders. Settled sorts by settled time.

Best-practice designs

All ten: rows are real links, scope and group-by live in the URL, lists virtualise past 50, one polite live region for status, tabular numerals, truncation everywhere, reduced-motion honoured, archive with undo.

Flat inbox, project as glyph Best practice

Costs: at 40+ sessions the glyph column turns to noise.

D5 · RECOMMENDED CONTAINER

Status-first triage (inbox zero) Best practice

Sections are status tiers. Needs-you rows carry the verb as their primary action; running and recent rows recede. "Recent" is what's left of Active after the auto-settle rules have swept it; Snoozed and Settled sink to the floor. Group-by-project works inside each tier.

Costs: rows move between tiers while you look; pin anything touched in the last 60s. Done-unread settles on hover ✓ or on visit + 3d idle.

§6 · Session row redesign
