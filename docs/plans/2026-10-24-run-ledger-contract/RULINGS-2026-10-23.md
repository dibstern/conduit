# Run Ledger rulings after amendment step 1 (82tn.32.2, 2026-10-23)

Supplements AMENDMENT-2026-10-23.md. Rulings on oracle disputes raised in
/tmp/82tn-beads/art-hlk1f/report.md.

R1 (dispute D3). Every probe is an obligation and owns a retry deadline from
the moment it is issued (amendment step 1: each obligation owns its deadline;
the "every non-Ended state carries a Deadline" invariant). An interaction or
input probe that gets no answer is re-probed at its retry deadline; it does not
wait for an explicit retryable transport outcome. The decider's behaviour
stands; the oracle changes.

R2 (dispute D2). A permission that times out is answered with exactly
`{ decision: "reject", reason: "timeout" }`. The decider's encoding stands; the
oracle changes.

R3 (property traces). A Run Input whose start or steer has been issued but has
no transport evidence yet is Dispatching, never Delivered/sent (amendment
rule 3B). The current model cannot express Dispatching, so the property traces
stay blocked until step 3 adds it; at step 3 the oracle must project
Dispatching here, not Delivered/sent.

D1 (quarantine plus native-session probe after a failed kill) is open, pending
the user's decision.
